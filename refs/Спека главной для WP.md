## 4. Сетка и ритм

- Контейнер `max-width: 1160px`, боковые отступы 60px (desktop), центрирование.
- Вертикальный ритм между секциями — **88px** (первая после шапки — 72px). Внутри секции заголовок и контент — 26px.
- Секции разделяются воздухом, не линиями и не рамками. Единственные линии: под топбаром, под шапкой, над футером.
- Сетки: фичи 2×2, курсы и статистика и блог — по 3 в ряд, gap 16–20px.
- Двухколоночные блоки: `minmax(0,1fr)` + фиксированные 480–520px.

## 5. Структура секций (порядок сверху вниз)

1. **Топбар** — 36px, `--surface-2`, слева дескриптор, справа телефон и почта.
2. **Шапка** — 68px, белая, логотип-квадрат 38px + название + подпись; меню; кнопка «Записаться» + корзина.
3. **Первый экран** — бейдж-пилюля, H1, лид, две кнопки (44px), под ними полоса из трёх фактов (84 / 800 ₽ / до 8) через `border-top`. Справа — карточка визуала.
4. **Логотипы вузов** — надзаголовок + ряд из 4 логотипов, ч/б.
5. **«Сделаем вместе — Шаг в будущее»** — левая колонка 360px (`position:sticky`), справа 4 карточки-фичи с иконками 40px в плитке `--accent-tint`.
6. **«Курсы и направления»** — заголовок + ссылка «Все курсы →», 3 карточки: обложка 16/10, чип класса, название, описание, цена + кнопка.
7. **«Интенсивная подготовка»** — фото 4/3 слева, справа чек-лист из 6 пунктов, плашка «2 часа / 800 ₽», две кнопки.
8. **Статистика** — 3 белые карточки с крупными числами.
9. **«Как проходят наши занятия»** — 3 последних записи блога.
10. **CTA + форма** — слева заголовок, лид и контакты с иконками; справа белая карточка формы с приподнятой тенью.
11. **Футер** — 3 колонки: реквизиты и соцсети / карта 16:9 / юридическая информация и документы; ниже копирайт над `border-top`.

## 6. Компоненты

**Кнопка.** Высота 38px (в шапке и карточках) или 44–46px (главные CTA), `padding: 0 18–22px`, `border-radius: 9px`, `font: 600 14–15px`, `white-space: nowrap`.
Primary — `--accent` / белый текст, `:hover` → `--accent-hover`.
Secondary — белый фон, `1px solid --border`, текст `--text-2`, `:hover` — фон `--surface-2`.
`:focus-visible` — `outline: 2px solid --accent; outline-offset: 2px`.

**Карточка.** `--surface`, `1px solid --border`, радиус 14px, `--shadow-card`, паддинг 20–26px. Для карточек с обложкой — `overflow: hidden`, паддинг только у текстовой части.

**Чип.** `padding: 4px 10px`, pill, `font: 600 11px`, uppercase, letter-spacing .04em, фон `--accent-tint`, текст `--accent-hover`.

**Поле формы.** Label 13px/500/`--text-2` + инпут 42px, `1px solid --border`, радиус 9px, фон `--surface-2`, `:focus` — рамка `--accent` и `box-shadow: 0 0 0 3px rgba(59,91,219,.12)`.

**Иконки.** Только из `src/js/common/icons.js`: users, camera, file, star, check, phone, mail, pin, chevron, arrow-right. Штрих 1.6, `stroke: currentColor`. Не мешать наборы.

## 7. Адаптив

- `≥1200px` — как в макете.
- `900–1199px` — контейнер по ширине окна, отступы 32px; двухколоночные блоки остаются, правая колонка ужимается до `minmax(0,440px)`.
- `600–899px` — все двухколоночные блоки в одну колонку (визуал под текстом), фичи и курсы 2 в ряд, футер 2 колонки.

## 9. Правила, которые нельзя нарушать

- Ни один текст на странице не менять — копия берётся с future-step.ru и из ACF как есть.
- Максимум один акцентный цвет на компонент: либо синяя заливка, либо синий текст, не оба.
- Плашки `--accent-tint` — только под иконки и чипы, не как фон блоков.
- Никаких вложенных карточек (карточка внутри карточки) — плоская иерархия.
- Пустой блок не рендерить: нет данных — секция не выводится, а не показывает заглушку.
