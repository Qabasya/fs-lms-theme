# Правила разработки WordPress / WooCommerce

1. **Версии**: Мы используем WordPress 6.x и WooCommerce 9.x. Не предлагай устаревшие функции (например, избегай `get_post_meta` там, где есть геттеры объектов WC).
2. **Получение товаров**: Всегда используй `wc_get_product( $id )` и работай с объектом `WC_Product`, а не с массивами постов.
3. **Безопасность**: Все данные из `$_POST` или `$_GET` должны проходить через `sanitize_text_field()`, `absint()` или соответствующие sanitize-функции WP. Все выводы через `esc_html()`, `esc_url()`, `wp_kses_post()`.
4. **Хуки**: Если ты не уверен в названии хука WooCommerce, сначала найди его в файлах `wp-content/plugins/woocommerce/` с помощью поиска, прежде чем предлагать код.
5. **Архитектура**: Используй объектно-ориентированный подход. Избегай глобальных переменных. Следуй принципам SOLID.
